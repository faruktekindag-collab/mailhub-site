MailHub – Gizlilik Politikası / Privacy Policy

Son güncelleme / Last updated: 10.11.2026

1. Hangi verilere erişilir? / What data is accessed?

Kullanıcı bir hesabı bağladığında MailHub, kullanıcının izin verdiği kapsamlarla şu verilere erişir: e-postalar ve klasörler/etiketler (okuma, taslak oluşturma, gönderme, okundu/arşiv işaretleme), takvim etkinlikleri ve hesabın e-posta adresi. Hesap girişi yalnızca Google'ın veya Microsoft'un kendi sayfasında yapılır; MailHub şifreleri görmez ve saklamaz.

When a user connects an account, MailHub accesses, with the scopes the user grants: emails and folders/labels (read, create drafts, send, mark read/archive), calendar events and the account's email address. Sign-in happens only on Google's or Microsoft's own page; MailHub never sees or stores passwords.

2. Veriler nasıl kullanılır? / How is data used?

Veriler yalnızca kullanıcının kendisine e-postalarını gösterme, arama, yanıtlama, son tarihleri ve yapılacakları çıkarma amacıyla kullanılır. Reklam, profil çıkarma veya başka bir amaçla kullanılmaz. Bir e-postayı gönderme gibi geri alınamaz işlemler yalnızca kullanıcı ekranda onayladıktan sonra yapılır.

Data is used only to show the user their own email, search it, reply, and extract deadlines and to-dos. It is not used for advertising, profiling or any other purpose. Irreversible actions such as sending an email happen only after the user confirms on screen.

3. Nerede saklanır? / Where is it stored?

E-posta önbelleği ve erişim anahtarları, kullanıcının kendi bilgisayarında veya kendi sunucusunda çalışan MailHub sunucusunda saklanır. Erişim anahtarları (yenileme jetonları) AES-256-GCM ile şifrelenir. Sunucuya yalnızca kayıtlı cihaz sertifikası olan cihazlar bağlanabilir. Kayıtlarda e-posta içeriği tutulmaz.

The email cache and access tokens are stored on the MailHub server that runs on the user's own computer or own server. Refresh tokens are encrypted with AES-256-GCM. Only devices with a registered device certificate can connect to the server. Logs do not contain email content.

4. Paylaşım / Sharing

Kullanıcı verileri satılmaz, kiralanmaz ve üçüncü taraflarla paylaşılmaz. Tek istisna: kullanıcı bir e-posta için yapay zekâ yardımını (ör. taslak önerisi) açıkça istediğinde, yalnızca seçilen yazışma bu iş için Anthropic'in Claude API'sine gönderilir; bu özellik hesap bazında kapatılabilir.

User data is not sold, rented or shared with third parties. The only exception: when the user explicitly asks for AI help with an email (e.g. a draft suggestion), only the selected thread is sent to Anthropic's Claude API for that task; this feature can be turned off per account.

5. Google API verileri / Google API data

MailHub's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

MailHub'ın Google API'lerinden aldığı bilgileri kullanması ve başka bir uygulamaya aktarması, Sınırlı Kullanım (Limited Use) şartları dahil olmak üzere Google API Hizmetleri Kullanıcı Verileri Politikası'na uyar.

6. Silme ve erişimi kaldırma / Deletion and revoking access

Kullanıcı bir hesabı MailHub'dan kaldırdığında o hesabın erişim anahtarları ve tüm önbellek verisi sunucudan silinir. Erişim ayrıca istenildiği zaman Google hesap izinleri veya Microsoft hesap ayarlarından geri alınabilir.

When a user removes an account from MailHub, that account's tokens and all cached data are deleted from the server. Access can also be revoked at any time from Google account permissions or Microsoft account settings.
